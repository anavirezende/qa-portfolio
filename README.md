## 📌 Sobre

Este repositório reúne artefatos de qualidade que produzi ao testar o **WebDojo**, aplicação de prática do curso [Ninja do Cypress](https://ninjadocypress.com.br), do Fernando Papito.

> ⚠️ **Aviso:** o código do WebDojo e o material do curso **não** estão aqui, pois são de uso exclusivo dos alunos. Este repositório contém apenas artefatos de QA escritos por mim.

## 🤖 Automação relacionada

Os testes automatizados com Cypress que fiz como exercício do curso estão em [webdojo](https://github.com/anavirezende/webdojo) (fork do curso). Para um projeto de automação autoral, veja o [Projeto_Bootcamp_QA](https://github.com/anavirezende/Projeto_Bootcamp_QA).

## 🎯 Como eu trabalho

- Parto dos requisitos e do comportamento esperado para decidir o que testar.
- Priorizo cenários por risco e impacto.
- Escrevo casos claros o bastante para outra pessoa reproduzir.
- Registro bugs com passos, resultado atual, resultado esperado e evidência.
